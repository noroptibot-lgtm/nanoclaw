# Content Viral AI System — noevarner.ai Framework

Transcribed from Instagram reel @noevarner.ai — 60k followers, 10M+ views in ~5 months.

## The 3-Step System

### Step 1: Data Collection

**Your own data:**
- Scrape your entire Instagram with Claude Code
- Download all content and analyze: hooks, visual hooks, spoken hooks, all metrics, outlier scores
- Know exactly what's working and what's not

**Competitor data:**
- If you're starting with no data → take other people's data
- Scrape competitors: hooks, metrics, outlier scores
- Also scrape personal brand experts — they have hooks dialed to a science

**Key rule:** Copy their **frameworks**, not their hooks exactly.
- A framework = "I'm going to show you how to use X so you can do Y"
- Plug and play values like a mad lib template

---

### Step 2: Connect Claude Code to Data Sources

Connect Claude Code to read:
1. All of your own content
2. All competitor content
3. All personal brand coach content

Have it produce full analysis:
- What are competitors doing that's winning?
- What am I doing that's working?
- What are the coaches doing that's working?

---

### Step 3: Hooks — The Only Thing That Matters

**The 4 parts of a hook (all must align):**

| Hook Type | Definition |
|-----------|------------|
| **Spoken hook** | What is said in the first 3 seconds |
| **Text hook** | What is on screen |
| **Audio hook** | What is being heard |
| **Visual hook** | What is being seen |

> "Nobody cares about what comes after the first three seconds if you can't get them sucked in."

**Formula for a viral video:** All 4 hooks aligned perfectly into one opening moment.

**Real example from creator's two 1M-view videos:**
- Visual hook: flipping the phone up
- Text hook: something curiosity-driving on screen
- Spoken hook: speaking immediately
- Audio hook: music aligned

## How to Apply This with Claude Code

```
1. Use Claude Code to scrape Instagram profile → extract all reels metadata
2. Pull outlier scores, hook text, view counts
3. Identify top 20% performers — what do their hooks have in common?
4. Scrape 3-5 competitors → same analysis
5. Build a hook template library from patterns found
6. Before every video: run the 4-hook checklist (spoken/text/audio/visual)
```

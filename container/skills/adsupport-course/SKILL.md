## Key Frameworks

### Conversion Heuristic (MECLABS)

```
C = 4M + 3V + 2(I - F) - 2A
```

- **M = Motivation** — how warm traffic is (target the right ICP)
- **V = Value Proposition** — appeal, exclusivity, clarity, "why this/you/now"
- **I = Incentive** — bonuses, guarantees, urgency, scarcity
- **F = Friction** — mental/time/fiscal cost (short forms, clear pages)
- **A = Anxiety** — trust, social proof, testimonials, action clarity

### Ad Consumption Flow

1. Hook/thumbnail stops scroll
2. Headline read
3. Decide: watch video or read copy
4. Copy drives CTA click

### Hook Categories

- Power Questions
- Counterintuitive Statements
- Big Bold Claim
- Case Study/Testimonial

### Learning Phase Exit

- Meta: 50 conversions / 7 days per adset
- YouTube: 1-2 weeks (up to 4)

### Scale Targets

- 30 days to break even
- 2.5x cash ROAS / 4x revenue ROAS = scalable
